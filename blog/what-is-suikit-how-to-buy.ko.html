SuiKit이란 — 그리고 구매 방법

SuiKit은 Sui의 중앙 지정가 호가창(CLOB)인 DeepBook V3용 트레이딩 봇을 구축하기 위한 소스 공개 개발 키트입니다. 메인넷에서 실제로 동작한 봇의 검증된 골격으로, 서비스·시그널 피드·수익 보장이 아닌 소스 코드와 문서로 판매됩니다.

포함 내용

  • 실행 엔진 — BalanceManager 라이프사이클 전체(자유 잔고 vs 잠금 잔고), 원자적 취소·주문, MoveAbort 코드 3 완화, gas 리저브 로직.
  • 의사결정 레이어 — 결정론적 5단계 퀀트 엔진. DeepSeek 오버레이는 선택 사항이며, 어떤 LLM도 호가창을 건드리지 않습니다.
  • 운영 도구 — 라이브 HTML 대시보드, Telegram 알림, 체결·원가 추적, 에러 워처, 정체 모니터링이 기본으로 포함됩니다.

모든 것은 클론해서 읽는 비공개 GitHub 저장소로 제공됩니다. 추천하는 활용법은 AI 코딩 에이전트에 repo를 읽히는 것입니다 — 추측이 아니라 검증된 답에서 시작합니다.

아닌 것

  • 관리형 서비스가 아닙니다 — 직접 실행합니다.
  • 시그널 그룹이 아닙니다 — 호출도 카피 트레이딩도 없습니다.
  • 수익 보장은 없습니다 — 전략은 학습용 레퍼런스 구현입니다.
  • 공식 제품이 아닙니다 — SuiKit은 독립 프로젝트로 Mysten Labs, Sui Foundation, DeepBook과 무관합니다.

구매 방법 — 단계별

  • 1. 체크아웃 열기 — 랜딩 페이지에서 “월렛 연결 & 결제”를 클릭합니다.
  • 2. Sui 월렛 연결 — Slush, Sui Wallet, Suiet 등 wallet-standard 호환 Sui 월렛. 모바일에서는 월렛 앱 내장 브라우저에서 페이지를 여세요.
  • 3. 100 USDC 결제(Sui 메인넷) — 서명 한 번, USDC 전송 한 건. gas는 평소처럼 월렛의 SUI로 지불됩니다. 서명을 요청하는 것은 이것뿐입니다.
  • 4. Telegram 봇 열기 — 결제 화면의 링크가 트랜잭션 digest를 첨부해 @sui_kit_bot으로 연결됩니다.
  • 5. GitHub 사용자명 전송 — 봇이 digest를 온체인 검증한 뒤 비공개 repo로 초대합니다. 보통 1분 이내입니다. 이메일 추가는 선택 사항이며 확장 에디션 우선 초대를 받을 수 있습니다.

연결할 수 없는 월렛으로 결제하나요? 임의의 월렛이나 거래소에서 체크아웃에 표시된 판매자 주소로 100 USDC를 보낸 뒤, 같은 방법으로 트랜잭션 digest를 봇에 보내면 됩니다. 검증은 온체인에서 이루어지므로 어떤 월렛이 결제했는지는 무관합니다.

얼리 액세스는 $100 USDC이며 정가는 $199입니다. 1회 결제로 repo 평생 액세스.
