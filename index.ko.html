개요

하나의 키트, 제대로 갖추는 데 몇 달이 걸린 세 개의 레이어.

DeepBook V3는 실제로 붙여보기 전까지는 단순해 보입니다. 이 키트는 메인넷에서 실제로 거래한 봇의 검증된 골격입니다 — 서비스나 시그널이 아닌, 소스 코드와 문서로 판매합니다.

01

실행 엔진

BalanceManager 라이프사이클(free / locked / settled), 원자적 cancel+place 트랜잭션, MoveAbort code 3 대응, gas 리저브 로직 — 문서에는 나오지 않는 부분들입니다.

02

의사결정 레이어

결정론적 5단계 퀀트 판단 + 선택적 DeepSeek 오버레이 하나. 데이터가 없을 때 LLM이 북을 건드리지 않습니다 — 주문은 그대로 유지됩니다.

03

운영 툴링

라이브 HTML 대시보드, Telegram 알림 & 제어, 체결 감지, 원가 추적, 에러 워처, 정체 모니터링까지 기본 제공.

repo 내부

엣지 케이스가 곧 제품입니다.

01

잔액 라이프사이클, 제대로

풀별 free vs locked vs settled 잔액을 추적하고, 온체인 상태와 동기화하고, 오픈 주문과 정합성을 맞춥니다 — 봇이 없는 돈으로 주문하는 일이 없도록.

02

MoveAbort code 3 회피

부족하거나 잠긴 DEEP 수수료 잔액을 자동 감지하고 전환 pay_with_deep=false — DeepBook V3 주문에서 가장 흔한 조용한 실패입니다.

03

원자적 주문 관리

취소와 발주를 하나의 트랜잭션으로. 주문 TTL 7일 주기 재연장. 오래된 가격 필터링. 서브 풀 정리. 전부 배선되어 있고 전부 주석 처리되어 있습니다.

04

gRPC 네이티브 클라이언트

Sui gRPC 직접 연결 + 구 JSON-RPC 인터페이스를 미러링하는 호환 레이어 — deprecated 엔드포인트도, 재작성도 없습니다.

05

체결 & 원가 추적

체결 감지, 원가 유지, 재시작 간 trailing 상태와 hold 벤치마크 추적 유지 — 모든 전략에 필요하지만 아무도 쓰고 싶어하지 않는 장부 처리입니다.

06

기본값으로 안전

가격 데이터가 없으면 봇은 기존 지정가를 유지한 채 아무것도 하지 않습니다. 중복 인스턴스 잠금, 쿨다운, 일일 상한, 연속 손실 브레이크 내장.

실제 코드

Real code, not a mockup.

저장소에서 그대로 가져온 실제 코드입니다 — 마케팅용으로 다듬지 않았습니다. 봇은 취소와 주문을 하나의 트랜잭션으로 묶어 호출 사이의 빈틈을 없앴고, 하이라이트된 줄은 DeepBook V3에서 가장 흔한 조용한 주문 실패에 대한 워크어라운드입니다. 이 플래그가 존재하는 이유 →

// src/services/DeepBookService.js — excerpt
for (const order of allOrders) {
  tx.moveCall({
    target: `${PKG}::pool::place_limit_order`,
    arguments: [
      tx.object(config.id), managerObj, proof,
      /* clientOrderId · expType · price · qty · side */
      tx.pure.bool(false), // pay_with_deep=false: avoids code=3 on insufficient DEEP
      tx.pure.u64(orderTtl), // 7-day order TTL
      tx.object('0x6') // Clock
    ],
    typeArguments: [config.baseType, config.quoteType]
  });
}

  • JavaScript를 작성할 줄 알고, 모든 엣지 케이스를 직접 재발견하지 않고 DeepBook V3에서 빌드하고 싶은 분.
  • 백서가 아니라 동작하는 BalanceManager 실행 레퍼런스를 원하는 분.
  • 검증된 플러밍 위에 자신만의 전략을 쓸 계획인 분.
  • 자체 인프라로 운영하며 키, 사이즈, 게이트를 완전히 통제하고 싶은 분.

이 키트는 아닙니다…

  • 수익성 있는 트레이딩 시스템, 시그널 서비스, 운용 상품이 아닙니다.
  • 금융 조언이 아닙니다 — 무엇을 사고팔지는 여기에 없습니다.
  • 호스티드 봇이 아닙니다 — 실행도, 리스크도, 키도 당신의 것입니다.
  • 재판매 불가 — 라이선스는 개인 사용이며 재배포는 금지됩니다.

FAQ

솔직한 답변.

이 봇은 돈을 벌어주나요?

그런 주장은 하지 않습니다 — 할 수도 없습니다. 이 키트는 DeepBook V3용 실행 인프라와 구현 노하우를 판매합니다. 포함된 전략은 연구와 확장을 위한 레퍼런스 구현이며 수익 약속이 아닙니다. 디지털 자산 거래에는 실제 손실 위험이 있습니다.

실행에 필요한 것은?

Node.js 20+, DeepBook V3 BalanceManager 오브젝트가 있는 Sui 월렛, gas용 소량의 SUI. DeepSeek API 키와 Ollama는 선택 사항 — 결정론적 퀀트 엔진은 LLM 없이 동작합니다.

액세스는 어떻게 전달되나요?

Sui 월렛(Slush, Sui Wallet 등)을 연결하고 온체인으로 $100 USDC를 결제한 뒤, 결제 후 표시되는 링크로 트랜잭션 digest와 GitHub 사용자명을 보내세요. 결제가 온체인에서 확인되면 비공개 리포지토리에 초대됩니다 — main 읽기 권한, 모든 문서와 향후 커밋 포함.

전달은 즉시입니다: Telegram 봇이 digest를 온체인에서 검증하고 GitHub 초대를 몇 초 만에 보냅니다.

얼리 구매자에게 추가 혜택이 있나요?

네. 이메일 주소를 등록한 구매자(선택 사항 — digest + GitHub 사용자명과 함께 보내기만 하면 됩니다)는 우선 초대와, 확장 에디션 출시 시 얼리 액세스 혜택을 받습니다. 등록은 repo의 주요 업데이트 소식을 받는 방법이기도 합니다.

어떤 풀에서 거래하나요?

실행 레이어는 풀에 구애받지 않습니다. 레퍼런스 설정은 깊이를 위해 SUI/USDC에 집중하고 서브 풀(DEEP, WAL, USDSUI, NS)은 정리 대상으로 다룹니다 — 확장 가능한 패턴입니다.

환불 정책은?

결제는 온체인 USDC로 이루어지며 취소할 수 없습니다. 전부 전달되는 디지털 소스 액세스이므로, 모든 판매는 최종이며 환불 불가 입니다 — 결제 확인 후. 유일한 예외는 저희 측 과실(예: 결제는 확인됐으나 repo 초대가 전달되지 않은 경우)뿐입니다. 궁금한 점은 구매 전에 문의하세요.

재배포하거나 재판매할 수 있나요?

안 됩니다. 라이선스는 개인 사용만 허가합니다 — 본인을 위한 사용, 열람, 수정. 공개 재배포와 재판매는 금지됩니다. repo의 LICENSE 파일을 참조하세요.

프로덕션에서 검증됐나요?

이 코드베이스는 Sui 메인넷에서 실제로 동작한 봇의 스냅샷입니다. 다만 환경은 다릅니다 — README에도 실전 운영은 본인 책임임이 명시되어 있습니다. 작게 시작하고, 대시보드를 보고, 킬 스위치 스크립트를 준비하세요.

어떤 네트워크와 자산을 받나요?

USDC, Sui 메인넷만 지원. 체크아웃은 월렛에서 판매자의 Sui 주소로 정확히 $100 USDC를 전송하는 하나의 트랜잭션에 서명합니다 — 다른 체인이나 토큰은 지원하지 않습니다.

왜 구독이 아니라 일회 결제인가요?

더 낮은 가격으로 더 많은 빌더에게 닿고 싶기 때문입니다. $100 한 번의 결제로 개인에게 키트를 접근 가능하게 유지하고, main의 모든 향후 커밋까지 포함됩니다 — 월정액도, 등급 제한도 없습니다.

Sui 또는 DeepBook의 공식 제품인가요?

아닙니다. SuiKit은 독립 프로젝트이며 Mysten Labs, Sui Foundation, DeepBook과 제휴·보증·후원 관계가 없습니다. Sui와 DeepBook은 각 소유자의 상표이며, 여기서의 언급은 설명 목적일 뿐입니다.

구매 전에 질문하려면 어떻게 하나요?

가장 빠른 답변은 Telegram으로 문의해 주세요 — 키트 범위, 호환성, 구매 절차에 대한 질문은 무엇이든 환영합니다. 이메일 contact@suikit.dev도 가능합니다. 기술적 질문에는 답하지만 금융·투자 조언은 제공하지 않습니다.
