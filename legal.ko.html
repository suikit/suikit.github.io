약관 & 개인정보

최종 업데이트: 2026-11

판매 약관

Sui DeepBook V3 Bot Kit(이하 "키트")을 구매함으로써 귀하는 다음 약관에 동의합니다.

  • 구매 내용. 키트의 소스 코드와 문서가 포함된 비공개 GitHub 리포지토리에 대한 읽기 권한. Sui 메인넷에서 $100 USDC 일회 결제가 온체인으로 확인된 후 부여됩니다.
  • 라이선스. 개인 사용 전용 — 본인을 위해 코드를 사용, 열람, 수정할 수 있습니다. 코드의 재배포, 재판매, 공개 게시는 금지됩니다. 라이선스 전문은 리포지토리의 LICENSE 파일에 포함되어 있으며, 본 요약과 충돌하는 경우 해당 전문이 우선합니다.
  • 전달. 초대는 결제 확인 후 발송됩니다 — 초대 봇이 가동되면 자동으로, 그 전까지는 수동으로(보통 24시간 이내) 처리됩니다.
  • 모든 판매 최종. 온체인 결제는 취소할 수 없습니다. 결제가 확인된 후에는 저희 측 과실로 전달이 실패한 경우를 제외하고 환불되지 않습니다.
  • 금융 조언 아님. 키트는 개발 인프라이자 레퍼런스 자료입니다. 수익성을 주장하지 않으며, 투자 조언이 아니고, 자금을 대신 운용하지도 않습니다.
  • 리스크. 모든 거래 결정, 키, 사이즈를 포함하여 소프트웨어 실행은 본인 책임입니다. 자동 거래는 자본을 잃을 수 있습니다. 명시적이든 묵시적이든 어떠한 보증도 제공되지 않습니다.
  • 독립성. 이 프로젝트는 Mysten Labs 또는 Sui Foundation과 제휴·보증·후원 관계가 없습니다. Sui와 DeepBook은 각 소유자의 상표입니다.
  • 자격. 거주 관할에서 법적 성년이어야 합니다. 포괄적 국제 제재 대상 관할 지역의 거주자 또는 체류자에게는 제공되지 않습니다.
  • 디지털 콘텐츠 및 철회권. 키트는 결제 확인 즉시 전달되는 디지털 콘텐츠입니다. 구매함으로써 즉시 전달에 동의하며, 관련 소비자법이 허용하는 최대 범위 내에서 철회 또는 취소 권리를 상실함을 인정합니다.
  • 세금. 가격은 세금 별도입니다. 관할 지역에서 적용되는 VAT, GST, 판매세 등의 의무는 구매자가 부담합니다.

개인정보

액세스 전달에 필요한 최소한의 정보만 수집합니다:

  • 월렛 주소 및 트랜잭션 digest — 온체인 결제 확인에만 사용됩니다.
  • GitHub 사용자명 — 리포지토리 초대 발송에만 사용됩니다.
  • 이메일 주소(선택) — 구매 확인, repo 업데이트 공지, 향후 에디션 우선 초대에만 사용됩니다.

귀하의 정보를 제3자에게 판매하거나 공유하지 않으며, 결제 카드 데이터를 저장하지 않습니다(결제는 온체인 전용). 이 사이트는 쿠키를 사용하지 않고 개인 데이터를 수집하지 않는 Cloudflare Web Analytics를 사용합니다. 이메일 또는 GitHub 연동의 삭제는 언제든지 Telegram 또는 이메일로 요청할 수 있습니다.
